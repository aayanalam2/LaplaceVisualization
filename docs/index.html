2D Laplace Equation Visualizer

Solves Laplace's equation on a square grid by Jacobi iteration, with Dirichlet or Neumann conditions on each edge. This is a browser version of a PyQt5 and Manim desktop tool; the solver is the same, but here it runs live instead of rendering a video.

The desktop version skips corners when applying Neumann conditions, so a corner between two Neumann edges keeps its initial value of zero. Unchecking this reproduces that behaviour.

Presets

Jacobi iteration on a 5-point stencil. Each sweep sets every interior point to the average of its four neighbours, then applies Neumann edges as a ghost-node copy of the adjacent interior row or column. It stops when the largest change in one sweep falls below the tolerance, with a floor of ten iterations. Source on GitHub.
